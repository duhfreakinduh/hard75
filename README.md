# HARD75

A mobile-first 75-day discipline tracker built for Joshua Shanks.

## Goals
- Track every daily requirement in one place
- Make water, workouts, reading, photo, diet, and faith habits easy to check off
- Store progress locally on the device
- Show day, streak, completion percentage, and restart history
- Work well as a phone-friendly web app

## First version
This repository is being initialized with a lightweight HTML/CSS/JavaScript app so it can run without a backend or account.
