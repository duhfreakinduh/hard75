# HARD75

A simple, mobile-first 75-day discipline tracker built for Joshua Shanks.

## Core idea
Every workout has two levels:

- **FLOOR** — the simplest intentional 45-minute workout for rough, busy, or low-energy days.
- **CEILING** — the full detailed workout plan for days when you can push harder.

The floor never shortens the workout requirement. It exists to remove decision fatigue, not the work.

## Included
- Daily 75-day progress tracker
- Floor / Ceiling workout toggle
- Detailed Planet Fitness workout rotation
- Outdoor family / pet walking plans
- 45-minute workout timers
- 7-day rotating high-protein meal plan with portions and prep shortcuts
- Gallon water tracker
- 10-page reading tracker
- Progress-photo checklist
- Daily scripture and prayer habit
- Notes, restart count, challenge map, backup / restore
- Local device storage — no login or backend required

## App files
- `index.html` — mobile UI
- `styles.css` — responsive design
- `plans.js` — meal, workout, and faith plans
- `app.js` — tracking, timers, persistence, and Floor / Ceiling controls
- `manifest.webmanifest` — installable web-app metadata
